# 灵感爆爆爆浏览器插件隐私政策

生效日期：2026-05-19

本隐私政策适用于「灵感爆爆爆」浏览器插件。该插件面向已获得授权的内容团队成员，用于在小红书和抖音页面上采集内容素材、评论、作者信息、媒体线索和任务执行结果，并同步到灵感爆爆爆内容工作台。

## 1. 我们收集哪些信息

插件可能处理以下信息：

- 页面内容：用户主动采集或工作台授权任务涉及的标题、正文、评论、作者信息、互动数据、媒体链接、页面链接等。
- 页面状态：当前页面地址、平台类型、页面类型、任务进度和采集状态。
- 授权信息：插件授权码换取的授权令牌、执行设备配对信息、执行设备状态。
- 本地账号信息：用户在插件内保存的平台账号名称、平台 cookies、额度和冷却状态。
- 媒体文件：用户主动下载或同步的图片、视频、Live Photo、评论图片等素材。
- 推送订阅信息：用于让内容工作台唤醒插件检查新任务的浏览器推送订阅信息。

插件不会收集健康信息、金融支付信息、精确地理位置，也不会读取与插件功能无关的网站内容。

## 2. 我们如何使用信息

这些信息仅用于：

- 识别用户当前打开的小红书或抖音页面。
- 执行用户主动发起的采集、下载、同步操作。
- 执行内容工作台下发的授权采集任务。
- 将采集结果同步到灵感爆爆爆内容工作台。
- 显示任务进度、失败原因、账号状态和执行设备状态。
- 改善采集准确度、任务稳定性和素材归档体验。

我们不会出售用户数据，不会把数据用于广告投放，不会把数据用于信用评估、借贷、保险、就业或其他与插件功能无关的用途。

## 3. 数据会发送到哪里

插件会与以下服务通信：

- 小红书和抖音相关域名：用于读取用户正在访问的页面内容和媒体资源。
- `https://lingganboom.fun`：用于插件授权、执行设备绑定、任务接收、进度回传、采集结果同步、媒体上传和推送订阅登记。
- 浏览器推送服务：用于接收内容工作台发送的轻量任务提醒，使插件更快检查是否有新任务。

除上述功能必需的通信外，插件不会把数据传给无关第三方。

## 4. Cookies 和账号信息

插件可能读取或写入小红书、抖音相关 cookies，用于用户授权的账号切换、账号健康检查和采集任务执行。

如果用户在插件中保存平台账号 cookies，这些信息会保存在本机浏览器存储中，用于后续采集任务。用户可以在插件中删除已保存账号。平台 cookies 不会被出售，也不会用于广告目的。

## 5. 数据保存

插件会在本机保存必要的设置、授权状态、采集缓存、账号状态和任务状态。同步到内容工作台的数据会按照工作台的数据管理规则保存。用户或团队管理员可以在内容工作台中管理、删除或归档相关数据。

## 6. 数据安全

插件与内容工作台通信时使用 HTTPS。授权码、执行设备令牌和任务令牌仅用于验证插件是否被允许连接团队工作台。我们会尽合理努力保护数据安全，但任何网络传输和本地设备存储都无法保证绝对安全。

## 7. 用户选择

用户可以：

- 不保存平台账号 cookies，只在当前浏览器登录状态下使用插件。
- 删除插件内保存的平台账号。
- 清除浏览器扩展数据或卸载插件。
- 联系团队管理员撤销插件授权或解绑执行设备。
- 在内容工作台中删除或归档已同步的数据。

## 8. 政策更新

如果插件的数据处理方式发生变化，我们会更新本政策，并在必要时通过内容工作台或插件说明告知用户。

## 9. 联系方式

请使用 Chrome Web Store 开发者账号中展示的支持邮箱，或联系灵感爆爆爆内容工作台管理员。

## 10. Chrome Web Store Limited Use Statement

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
