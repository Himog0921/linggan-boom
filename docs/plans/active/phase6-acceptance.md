## 当前验收边界

### 当前阻塞（2026-04-02）

- 基于 gstack `/browse` 的“带扩展离屏 Chromium”回归当前不可作为插件实机验收依据。
- 已现场验证：`BROWSE_EXTENSIONS_DIR=/.../dist browse goto https://www.douyin.com/...` 能正常打开页面，但页面内未出现 `灵感爆爆爆 / 批量采集视频 / 采集评论 / 评论图片区` 等插件注入按钮。
- 根因更像 QA 工具链限制而非本项目页面逻辑：gstack `browse/src/browser-manager.ts` 的 `launch()` 在扩展模式下仍走 `chromium.launch() + browser.newContext()`，而同文件 `launchHeaded()` 已明确注明“扩展需要 `launchPersistentContext()` 且要去掉 Playwright 默认的 `--disable-extensions` 参数”。
- 在此阻塞解除前，Phase 6 的“真实插件回归”仍需依赖手动 Chrome 加载已解压扩展，或先修复 gstack browse 的扩展加载模式。
