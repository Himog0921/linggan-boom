# Popup 顶部头部重排方案（2026-04-22）

> 目标：只优化 `popup` 顶部品牌容器的格局。  
> 已确认保留项：`长条 LG BOOM banner`、`灵感爆爆爆` 字样、右上 `平台 / 主题切换`。  
> 已确认删除项：`方形 logo`、`小红书数据采集工具箱` 副标题。

## 设计判断

### Visual Thesis

把头部做成一个“小海报”，只保留一个主视觉锚点，不再让多个带边框的小块互相抢视线。

### Content Plan

1. 主视觉：长条 `LG BOOM banner`
2. 品牌名：`灵感爆爆爆`
3. 右上控制：平台 badge + 主题切换

### Interaction Thesis

1. 头部不再承担“解释产品”的任务，只负责品牌识别和快速切换。
2. 右上两个控制必须明显是“工具”，不能和品牌主视觉处于同一视觉等级。
3. header 内部应形成一条清晰阅读路径：`banner -> 标题 -> 右上控制`

### 位置关系

- 右上角只放 `平台 badge + 主题切换`，固定成工具区。
- `灵感爆爆爆` 固定在左上角，作为头部起始点。
- `banner` 保持当前尺寸，不放大也不缩小。
- `banner` 不贴顶部，它要在 header 左侧区域里做垂直居中。
- 这里的“左侧对齐”指的是：`banner` 仍然属于左半区，但在垂直方向上居中，而不是贴左上或落在某个固定中段文案下面。
- `灵感爆爆爆` 和 `banner` 不强行贴在一起；两者是同一左侧品牌区里的上下关系，但视觉主角仍然是 `banner`。

### 这版的核心气质

- 不是“标题栏”
- 不是“横向导航”
- 更像一个左侧有主视觉、右上有工具的品牌头

### 尺寸建议

- `banner` 尺寸：保持当前版本大小不变
- `banner` 垂直位置：在 header 左侧区域做视觉居中
- `灵感爆爆爆`：放在左上，但字号比当前版本缩 `1` 档
- 右上两个 pill：保持同高、同一行，但整体视觉重量低于 banner

### 下一轮代码实现时的执行原则

1. `灵感爆爆爆` 固定在左上，作为品牌起始文字
2. `banner` 保持现有尺寸，只调整在左侧区域里的垂直居中关系
3. 右上 controls 继续保留，但要像“按钮”，不是像 header 主体
4. 黄色 header 内部要做出明显的“左侧品牌区 + 右上工具区”秩序，而不是平均铺开
5. 不新增任何副标题、解释文案或额外 logo

## 现状问题

当前这版的问题不是“信息太多”，而是“主次关系不够狠”：

- 长条 banner 和右上两个 pill 都在第一排，导致 banner 不够像主角。
- `灵感爆爆爆` 单独落到下一排，但没有形成完整的版式支点，看起来像被挤下去。
- 黄色大底内部空白偏散，左上重、右下轻，视觉重心不稳。
- header 里每一块都带强边框，结果谁都在强调自己。

## 方向 A：横向品牌轴

### 示意

```text
┌──────────────────────────────────────┐
│ [ LG BOOM ]               [小红书][AC] │
│ 灵感爆爆爆                              │
└──────────────────────────────────────┘
```

### 特点

- 最接近你当前这版，但关系更收敛。
- banner 在左上，标题紧跟在下方，形成一个左侧品牌轴。
- 右上 controls 保持一行，但要明显缩成次级信息。

### 优点

- 改动最小，容易落地。
- 风格延续现有 brutalist 语言，不容易翻车。

### 问题

- 还是偏“左右分栏”，header 的空场容易继续发散。
- banner 仍然像一个组件，不像真正的主视觉。

### 适合

- 如果你想保守一点，只在现有结构上做优化。

## 方向 B：海报式双层结构（推荐）

### 示意

```text
┌──────────────────────────────────────┐
│ [     LG BOOM banner 主视觉区      ] │
│ 灵感爆爆爆                [小红书][AC] │
└──────────────────────────────────────┘
```

### 特点

- 第一层只给 banner，当主视觉。
- 第二层才放标题和控制项。
- 这样阅读顺序非常明确：先看到品牌图形，再看到品牌名，最后看到工具按钮。

### 优点

- 最符合“只保留一个主视觉锚点”的思路。
- 黄色容器里的空白会更有秩序，不再像随便摊开的块。
- `灵感爆爆爆` 和 controls 共享一条基线，会比现在稳定很多。

### 风险

- banner 尺寸如果不够大，会显得虚。
- 第二行标题和 controls 的间距要控制好，否则会变成普通表单头。

### 适合

- 如果你想让 popup 顶部更像一个完整品牌头，而不是功能卡片。

### 推荐尺寸关系

- banner 宽度：约 header 内宽的 `58% - 66%`
- 标题字号：比当前略大一档，但不压过 banner
- controls：高度保持一致，整体缩成工具层

## 方向 C：标题主导，banner 退成签名

### 示意

```text
┌──────────────────────────────────────┐
│ 灵感爆爆爆                  [小红书][AC] │
│ [ LG BOOM banner ]                    │
└──────────────────────────────────────┘
```

### 特点

- 让中文品牌名成为第一识别点。
- banner 变成“签名条”，不再是视觉主角。

### 优点

- 更直接，中文可读性最好。
- 如果你觉得英文 banner 太抢，可以用这套。

### 问题

- 会削弱 `LG BOOM` 本身的辨识度。
- 容易做成普通标题栏，不够有记忆点。

### 适合

- 如果你希望“灵感爆爆爆”四个字是绝对核心，而不是 logo。

## 不建议的做法

- 不再引入任何方形 logo。
- 不再给 banner 再套一层重边框卡片再套卡片。
- 不再增加副标题、说明语、口号。
- 不要把平台 badge 和主题切换做得跟 banner 一样重。
- 不要在 header 里再塞第三行。

## 初始推荐（已被用户选择覆盖）

我建议直接走 **方向 B：海报式双层结构**。

原因很简单：

1. 你已经明确不要方形 logo，也不要副标题，那就应该让 `长条 banner` 真正成为唯一主视觉。
2. 现在最需要解决的不是“排齐”，而是“谁是主角”。方向 B 的主次最干净。
3. popup 很窄，越窄越不能搞多中心布局。双层结构比左右拼接更稳。
