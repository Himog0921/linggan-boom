# 抖音真实浏览器验收清单

更新日期：2026-05-18
适用版本：`linggan-boom` `2.0.12`

## 1. 使用边界

这份清单只用于真实 Chrome 验收，不替代 `npm run test:douyin`。

自动化测试已经覆盖代码层、任务协议、远程控制、媒体下载降级、验证码保护和发布包校验。真实浏览器验收只回答这些机器测试不能证明的问题：

- 用户已登录的抖音页面是否还能稳定显示插件入口。
- 抖音真实页面是否会触发验证码、登录拦截或页面结构变化。
- 真实评论长任务是否能持续写入。
- 评论图片和视频/图文媒体是否能下载到本地，并且文件可打开。
- 工作台远程派单是否能在真实页面中完成任务生命周期。

## 2. 前置条件

开始前必须确认：

- Chrome 中使用的是已登录抖音账号的同一个浏览器环境。
- Chrome 扩展详情页显示 `灵感爆爆爆` 已启用，版本为 `2.0.12`。
- 抖音站点权限已允许。
- 插件弹窗内正式站连接为 `https://lingganboom.fun`。
- 插件已授权并绑定执行设备。
- 数据页点击“获取 Cookie”后，抖音 Cookie 能成功保存为采集账号。
- 页面没有验证码、滑块、安全验证、登录弹窗。

如果出现验证码或安全验证：

- 不操作验证码。
- 记录触发页面、触发动作和插件提示。
- 通过标准不是“绕过验证码”，而是插件能暂停/拒绝任务，并给出可读原因。

## 3. 固定样本表

每轮验收前填好这些样本。不要临时换样本，否则前后结果不可比较。

| 样本类型 | 链接 | 验收用途 | 通过标准 |
|---|---|---|---|
| 单条视频 | 待填 | 视频采集、评论采集、视频下载 | 采集后数据面板出现 `dy_` 记录，视频文件可打开 |
| 图文/多图 | 待填 | 图文识别、图片下载、数据面板二次下载 | 图片进入媒体队列，下载文件可打开 |
| 博主页 | 待填 | 采集博主、批量视频、批量评论 | 页面右侧出现博主页按钮，批量任务有进度 |
| 有评论图片的视频 | 待填 | 评论图片区下载 | 只下载评论图片，不混入头像、表情、错误页 |
| 评论较多的视频 | 待填 | 长评论、翻页、二级回复 | 评论持续增加，层级关系正确 |
| 搜索关键词 | 待填 | 搜索页批量视频/评论 | 顺位、关键词、平台来源可追溯 |

## 4. 验收步骤

### 4.1 环境确认

1. 打开抖音首页或精选页。
2. 打开插件弹窗。
3. 确认插件能识别为抖音页面，但非采集场景时不会误启用采集。
4. 打开数据页，记录当前笔记/视频数、评论数、博主数。

记录：

```text
开始前数据：
笔记/视频：
评论：
博主：
抖音账号数量：
```

通过标准：

- 插件能打开。
- 当前平台识别为抖音。
- 非采集页不误显示可执行采集状态。

### 4.2 单条视频采集

1. 打开固定“单条视频”样本。
2. 确认页面右侧出现 `采集视频 / 下载视频 / 采集评论 / 评论图片`。
3. 点击 `采集视频`。
4. 打开数据页，确认新增或更新 `dy_` 记录。

通过标准：

- 按钮出现。
- 采集动作有明确完成提示。
- 数据面板可看到对应抖音记录。
- 标题、作者、链接不串到其他视频。

### 4.3 视频媒体下载

1. 在同一个视频详情页点击 `下载视频`。
2. 等待下载完成。
3. 打开本地下载文件。

2026-05-18 真实 Chrome 复验结果：

- 在作者页作品弹层点击 `下载视频` 后，下载目录新增 `灵感爆爆爆_抖音视频_ADHD _ 高中A娃本人讲一下我的家庭氛围大家有什么想问我的或者想让我回答的问.mp4`。
- 文件大小 `64,315,277` 字节，系统识别为 MP4；`ffprobe` 识别到 H.264 视频、AAC 音频，分辨率 `1280x720`，时长约 `483.35` 秒。

通过标准：

- 文件能下载。
- 文件不是空文件。
- 文件能正常播放或预览。
- 如果失败，插件给出可读原因。

### 4.4 评论长任务

1. 在固定“评论较多的视频”样本中点击 `采集评论`。
2. 设置评论上限建议从 `50` 开始。
3. 任务运行中观察右下角任务栏。
4. 测试暂停、继续、停止。
5. 打开数据页，确认评论数增加。

通过标准：

- 任务栏显示进度。
- 暂停后不继续刷评论，继续后恢复。
- 停止后保留已采集结果。
- 如果实际评论数少于设置上限，任务也要按真实结果显示完成，不能卡在“进行中”。
- 评论绑定到当前视频。
- 失败时能看到原因，不是静默结束。

### 4.5 评论图片区下载

1. 打开固定“有评论图片的视频”样本。
2. 点击 `评论图片`。
3. 设置评论扫描上限，建议从 `50` 开始。
4. 等待下载完成并打开文件夹或压缩包。

通过标准：

- 只下载评论图片。
- 不混入头像、表情、页面装饰图、错误页截图。
- 文件可打开。
- 无图评论不会被误报为下载失败。

### 4.6 图文/多图下载

1. 打开固定“图文/多图”样本。
2. 点击采集或下载入口。
3. 打开数据页，对已保存记录执行二次下载。

2026-05-18 数据面板复验结果：

- 修复前，面板曾显示 `共 0 条`，但本地库实际已有 `notes=355 / comments=4825 / authors=12`。
- 修复并重载插件后，数据面板显示 `共 355 条`，已保存抖音记录和“媒体”按钮可见。
- 用户真实复验确认：可以从数据面板的“媒体”按钮完成下载。

通过标准：

- 图文能识别为详情页。
- 图片候选不为空。
- 旧链接失效时能刷新后再下载。
- 下载文件可打开。

### 4.7 博主页批量视频

1. 打开固定博主页。
2. 确认页面右侧出现 `采集博主 / 批量视频 / 批量评论`。
3. 点击 `批量视频`，设置小批量数量，例如 `5`。
4. 运行中测试暂停、继续、停止。

通过标准：

- 批量任务有进度。
- 停止后保留部分结果。
- 采集结果属于当前博主。
- 不误采其他页面或旧弹层内容。

2026-05-18 已完成一次真实 Chrome 复验：

- 固定博主页：`高中ADHD分享（昉沄智坊）`。
- 小批量 `5` 条：本地记录 `status=done`，`itemsPlanned=5 / itemsSucceeded=5 / itemsFailed=0`。
- 更大批量任务：真实点击 `暂停 / 继续 / 停止` 后，任务条最终显示 `已停止`，本地记录 `status=stopped`，`itemsPlanned=20`，保留 20 个目标作品 ID。
- 未再出现上一轮复现过的停止收尾报错。

### 4.8 博主页批量评论

1. 打开固定博主页。
2. 确认页面右侧出现 `采集博主 / 批量视频 / 批量评论`。
3. 点击 `批量评论`，设置小批量作品数和评论上限。
4. 运行中测试暂停、继续、停止。

通过标准：

- 批量评论任务有进度。
- 暂停后能继续。
- 停止后本地记录进入停止态。
- 结果保留目标作品和已成功内容清单。

2026-05-18 已完成一次真实 Chrome 复验：

- 固定博主页：`高中ADHD分享（昉沄智坊）`。
- 启动设置：默认 `10` 条作品，评论上限 `20`。
- 真实点击 `暂停 / 继续 / 停止` 后，本地最新记录为 `batchComments`，`status=stopped`，`itemsPlanned=10 / itemsSucceeded=3 / itemsFailed=0`。
- 结果保留 10 个目标作品 ID、3 个成功内容 ID，`failedTargets=[]`，没有错误信息。

### 4.9 搜索页批量

1. 使用固定关键词打开抖音搜索页。
2. 确认页面右侧出现 `批量视频 / 批量评论`。
3. 设置小批量数量，例如 `5`。
4. 运行后检查数据面板记录。

通过标准：

- 搜索词被保留。
- 顺位可追溯。
- 采集记录来源为抖音。

### 4.10 工作台远程派单

1. 确认插件执行设备在线。
2. 在工作台创建或触发一个抖音采集任务。
3. 等待插件接单。
4. 观察任务状态从等待、执行中，到成功/失败/暂停。
5. 查看任务结果和失败原因。

通过标准：

- 任务能被当前插件工位接走。
- 任务状态变化可见。
- 成功时结果写回。
- 失败时原因可读，且能判断是否可重试。
- 安全验证时返回平台安全验证状态，不误报完成。
